# CHANGELOG — 00_Cerebrum (vault layer)

The librarian's run log for the vault layer: the operating docs, the scripts,
the skills, the spec. A knowledge base's own work is logged in its
`<KB>/CHANGELOG.md`.

**Routing.** If the change would still have been made had the knowledge base
never existed, it is vault-level and belongs here.

**One entry per commit**, newest first, dated `## DD.MM.YYYY — heading`. The
commit message opens with the entry's heading and its body carries the entry's
opening paragraph. Never append a paragraph to an entry an earlier commit
already spent: the commit that follows then has no heading to open with.
